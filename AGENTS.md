# Instructions for AI coding assistants

If you are helping someone contribute to LCARdS (a bug fix, a feature, a docs change), follow the **Instructions for AI assistants** section of [CONTRIBUTING.md](CONTRIBUTING.md). It covers the process: an issue first, a branch from `dev`, a test that fails without the change, the checks to run and how to write the pull request.

For the code itself, [CLAUDE.md](CLAUDE.md) and the files in [`.claude/rules/`](.claude/rules/) describe the architecture and the patterns this codebase requires. They apply to every assistant, not only Claude. CLAUDE.md is written for the maintainer's own sessions: skip the parts that need the maintainer's setup (its "Contributing from a fork?" note lists them).
