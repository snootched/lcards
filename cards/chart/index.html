Chart Card ​

custom:lcards-chart

Plots your Home Assistant sensors over time: lines, areas, columns, gauges, range bands, candlesticks and more. Charts pick up your LCARS theme colours and fonts automatically, so most charts need nothing more than a list of entities.

The card is built on ApexCharts, a very capable charting library. You don't need to know ApexCharts to use it: these pages cover everything LCARdS sets up for you.

Try it

  • In the card editor, Open Configuration Studio gives you a live preview while you add series, pick a chart type and adjust colours.
  • The Playground lets you edit chart YAML right here in the docs and see the result.

The charts on these pages are live previews drawn by the card's own code, using generated sample data.

Quick start ​

One sensor, last 24 hours:

yaml
type: custom:lcards-chart
sources:
  - entity: sensor.living_room_temperature

Two sensors as filled areas, with names in the legend:

yaml
type: custom:lcards-chart
chart_type: area
sources:
  - entity: sensor.living_room_temperature
    name: Living room
  - entity: sensor.outdoor_temperature
    name: Outside
style:
  legend:
    show: true

A week of daily energy use, from Home Assistant's long-term statistics:

yaml
type: custom:lcards-chart
chart_type: column
graph_span: 7d
sources:
  - entity: sensor.energy_consumption
    name: Energy per day
    statistics:
      type: change
      period: day

Where the data comes from ​

Each entry under sources is one series (one line, area or set of columns). A series gets its data from one of three places:

Which should I use?

  • Start with entity history. It is the simplest and shows exactly what Home Assistant recorded.
  • Switch to long-term statistics when the chart spans more than a few days, or the sensor changes so often that history gets slow. Statistics also last beyond the recorder's history limit.
  • Use an LCARdS data source when you want to plot a processed value (a smoothed line, a rate of change, a converted unit), or share one live value between several cards. Data sources are created when the dashboard loads and keep a limited number of recent points (up to 1,000), so they suit short windows. See Data Sources.
yaml
type: custom:lcards-chart
sources:
  # Entity history
  - entity: sensor.living_room_temperature

  # An attribute instead of the state
  - entity: climate.living_room
    attribute: current_temperature

  # Long-term statistics
  - entity: sensor.energy_consumption
    statistics:
      type: sum        # mean | min | max | sum | state | change
      period: day      # 5minute | hour | day | week | month

  # An LCARdS data source, plotting its smoothed values
  - datasource: living_room
    buffer: smoothed
data_sources:
  living_room:
    entity: sensor.living_room_temperature
    processing:
      smoothed:
        type: smooth
        method: exponential
        alpha: 0.3

Non-numeric entities

Charts plot numbers. States like on/off, open/closed and true/false are plotted as 1 and 0 automatically; use curve: stepline to draw them as steps. Other states (heat, home, docked, ...) don't plot on their own: pick a numeric attribute instead, or use a data source with enum_mapping to turn each state into a number. Chart Studio warns you when a series won't plot.

yaml
type: custom:lcards-chart
sources:
  - entity: light.living_room
    name: Living room light
    curve: stepline
    type: area
    opacity: 0.4

Gallery ​

Columns of hourly averages:

yaml
type: custom:lcards-chart
chart_type: column
sources:
  - entity: sensor.house_power
    name: Power
    group_by:
      func: avg
      duration: 1h

A heatmap of several sensors, one row each:

yaml
type: custom:lcards-chart
chart_type: heatmap
sources:
  - entity: sensor.kitchen_temperature
    name: Kitchen
    group_by: { func: avg, duration: 2h }
  - entity: sensor.bedroom_temperature
    name: Bedroom
    group_by: { func: avg, duration: 2h }
  - entity: sensor.outdoor_temperature
    name: Outside
    group_by: { func: avg, duration: 2h }

Gauges showing each sensor's current value:

Full examples ​

Weather panel ​

Outdoor temperature as a filled area with humidity on its own axis, frost and heat lines, and a tooltip that reads naturally:

yaml
type: custom:lcards-chart
chart_type: area
graph_span: 48h
yaxis:
  - id: temperature
  - id: humidity
    opposite: true
    min: 0
    max: 100
    decimals: 0
sources:
  - entity: sensor.outdoor_temperature
    name: Temperature
    unit: °C
    float_precision: 1
    group_by:
      func: avg
      duration: 30min
  - entity: sensor.outdoor_humidity
    name: Humidity
    type: line
    yaxis_id: humidity
    stroke_dash: 4
    group_by:
      func: avg
      duration: 30min
style:
  colors:
    series:
      - "var(--lcars-orange)"
      - "var(--lcars-blue)"
  fill:
    type: gradient
    gradient:
      opacityFrom: 0.6
      opacityTo: 0.05
  thresholds:
    - value: 0
      label: Frost
      color: var(--lcars-blue)
      dash: true
    - value: 20
      label: Warm
      color: var(--lcars-red)
  legend:
    show: true
    position: top
  formatters:
    xaxis_label: "ddd HH:mm"
    tooltip: "{seriesName}, {x|ddd [at] HH:mm}: {y}"

Energy fortnight ​

Daily energy use from long-term statistics, with each bar labelled and a line for the daily target:

yaml
type: custom:lcards-chart
chart_type: column
graph_span: 14d
span:
  end: day
sources:
  - entity: sensor.energy_consumption
    name: Energy per day
    unit: kWh
    float_precision: 1
    statistics:
      type: change
      period: day
style:
  colors:
    series:
      - "var(--lcars-yellow)"
  data_labels:
    show: true
    font_size: 10
  yaxis:
    decimals: 0
  thresholds:
    - value: 5
      label: Target
      color: var(--lcars-green)
  chart_options:
    plotOptions:
      bar:
        borderRadius: 4

Power monitor ​

The last six hours of a busy power sensor: the 10-minute average as an area, and the 10-minute peak as a thin line above it:

yaml
type: custom:lcards-chart
graph_span: 6h
sources:
  - entity: sensor.house_power
    name: Average
    type: area
    opacity: 0.35
    group_by:
      func: avg
      duration: 10min
  - entity: sensor.house_power
    name: Peak
    stroke_width: 1
    curve: stepline
    group_by:
      func: max
      duration: 10min
style:
  legend:
    show: true
  thresholds:
    - value: 2000
      label: High load
      color: var(--lcars-red)
      dash: true
  display:
    toolbar: true

A longer example with an LCARdS data source is at the end of Styling.
