Base SVG Filters ​

Filters change how the blueprint looks: dimmer, softer, grey or tinted, so the controls and lines on it stand out. They apply to the blueprint only; overlays stay sharp. The same filters work on the button and data grid cards (Filters).

filters ​

base_svg.filters is a list of filters applied to the blueprint, one after another. Each entry names a type and gives its value; mode: svg marks the SVG filter primitives, and CSS filters need no mode.

  • CSS filters (opacity, blur, grayscale ...) are quick and cover most needs. SVG filters (tint, feColorMatrix ...) do what CSS can't, such as a real colour tint.
  • The CSS filters run first, in list order, then the SVG filters, chained in list order: each one works on the result of the one before.
  • filters: [] clears them. A rule can crossfade the blueprint to other filters while a condition holds, such as a red tint on alert.
  • In the MSD Studio, the Base SVG tab's Filters (base_svg) section adds and edits them, with a guide to each type.
yaml
type: custom:lcards-msd-card
grid_options:
  columns: full
  rows: 5
msd:
  base_svg:
    source: builtin:ncc-1701-a-blue
    # faded and darker, with a blue tint over it
    filters:
      - type: opacity
        value: 0.6
      - type: brightness
        value: 0.8
      - mode: svg
        type: tint
        value:
          color: alpha(var(--lcars-blue), 0.2)
  view_box: [180, 270, 1600, 720]
More about filters
  • Older configs wrote filters as one map (opacity: 0.5, blur: 3px). Write a list of entries instead, as on this page.
  • Live values: filter values are fixed; templates and entity bindings don't work in them. Use a rule to change them with an entity.
KeyTypeDefaultDescription
filters[].typestringrequiredThe filter: one of the CSS filters or SVG filters below
filters[].valuenumber / string / objectper typeA number or string for a CSS filter, the keys listed below for the others
filters[].modestringcsscss or svg. Set svg for the SVG filters

CSS filters ​

The browser's own CSS filters: fade, blur, brighten, desaturate and shift the colours of the blueprint. Most take one number as value; blur and hue-rotate take a length or an angle as a string.

  • Stack several to combine them: a faded, slightly blurred blueprint is two entries.
  • Each type below has a playground: move the sliders to see it on a sample shape, and copy the YAML it prints.
yaml
type: custom:lcards-msd-card
grid_options:
  columns: full
  rows: 5
msd:
  base_svg:
    source: builtin:ncc-1701-a-blue
    # grey, softened and faded
    filters:
      - type: grayscale
        value: 1
      - type: blur
        value: 2px
      - type: opacity
        value: 0.6
  view_box: [180, 270, 1600, 720]

How see-through the blueprint is, from 0 (invisible) to 1 (solid). The usual way to push a busy blueprint into the background.

SVG filters ​

SVG filter primitives, for effects the CSS filters can't give: a real colour tint, colour matrices, glows, outlines and distortion. Each entry needs mode: svg, and its value is a set of keys.

  • They chain: each primitive works on the result of the one before it in the list, so a blur followed by a blend makes a glow.
  • tint is the friendly one: a single entry for a colour wash. The others are the browser's SVG primitives, named as in SVG (feGaussianBlur ...).
yaml
type: custom:lcards-msd-card
grid_options:
  columns: full
  rows: 5
msd:
  base_svg:
    source: builtin:ncc-1701-a-blue
    # a soft glow: blur the blueprint, then blend the blur back over it
    filters:
      - mode: svg
        type: feGaussianBlur
        value:
          stdDeviation: 6
      - mode: svg
        type: feBlend
        value:
          mode: screen
  view_box: [180, 270, 1600, 720]
KeyTypeDefaultDescription
modestringcssMust be svg for these
valueobjectper typeSee each type below

feGaussianBlur ​

A blur that chains with the other SVG filters, smoother than the CSS blur. The base for glows and soft shadows.

Loading live preview…

yaml
filters:
  - mode: svg
    type: feGaussianBlur
    value:
      stdDeviation: 4
KeyTypeDefaultDescription
value.stdDeviationnumber0How much to blur: 0 is none

feColorMatrix ​

Changes colours with a colour matrix: saturation, a hue turn, transparency from brightness, or a custom 4 by 5 matrix. For colour changes beyond the CSS saturate and hue-rotate.

Loading live preview…

yaml
filters:
  - mode: svg
    type: feColorMatrix
    value:
      type: saturate
      values: 1.5
KeyTypeDefaultDescription
value.typestringsaturatesaturate, hueRotate, luminanceToAlpha (darker parts become see-through) or matrix
value.valuesnumber / string / list1 for saturate, 0 for hueRotateThe saturation factor, the hue angle in degrees, or 20 numbers for matrix (a list or a string). Not used by luminanceToAlpha

feOffset ​

Moves the result by dx and dy px. With a blur and a blend, it makes a shadow of your own.

Loading live preview…

yaml
filters:
  - mode: svg
    type: feOffset
    value:
      dx: 3
      dy: 3
KeyTypeDefaultDescription
value.dxnumber0Move right (negative: left), px
value.dynumber0Move down (negative: up), px

feBlend ​

Blends the result so far back over the original blueprint with a blend mode. After a blur, screen or lighten gives a glow.

Loading live preview…

yaml
filters:
  - mode: svg
    type: feBlend
    value:
      mode: screen
KeyTypeDefaultDescription
value.modestringnormalAny of the 16 CSS blend modes: normal, multiply, screen, darken, lighten, overlay, color-dodge, color-burn, hard-light, soft-light, difference, exclusion, hue, saturation, color, luminosity

feComposite ​

Combines the result so far with the original blueprint by a compositing operator, or a formula of your own. For layering beyond the blend modes.

Loading live preview…

yaml
filters:
  - mode: svg
    type: feComposite
    value:
      operator: over
KeyTypeDefaultDescription
value.operatorstringoverover, in, out, atop, xor or arithmetic
value.k1number0arithmetic only: the result is k1 * a * b + k2 * a + k3 * b + k4 (a: the result so far, b: the blueprint)
value.k2number0arithmetic only
value.k3number0arithmetic only
value.k4number0arithmetic only

feMorphology ​

Thins (erode) or thickens (dilate) the blueprint's lines. For outlines, or heavier strokes on a fine drawing.

yaml

  - mode: svg
    type: feMorphology
    value:
      operator: dilate
      radius: 2
KeyTypeDefaultDescription
value.operatorstringerodeerode thins, dilate thickens
value.radiusnumber1How far to thin or thicken

feTurbulence ​

Noise for organic textures, usually followed by feDisplacementMap to warp the blueprint. On its own it draws only the noise, in place of the blueprint.

Loading live preview…

yaml
filters:
  - mode: svg
    type: feTurbulence
    value:
      baseFrequency: 0.02
      numOctaves: 3
KeyTypeDefaultDescription
value.typestringturbulenceturbulence (cloudy) or fractalNoise (softer)
value.baseFrequencynumber0.050 to 1: lower is larger features
value.numOctavesinteger11 to 10 layers of detail
value.seednumber0Change it for a different pattern

feDisplacementMap ​

Warps the image by the colours of the result before it: wavy, liquid or turbulent distortion. Put an feTurbulence right before it to give it something to warp by.

Loading live preview…

yaml
filters:
  - mode: svg
    type: feTurbulence
    value:
      baseFrequency: 0.02
      numOctaves: 3
  - mode: svg
    type: feDisplacementMap
    value:
      scale: 20
KeyTypeDefaultDescription
value.scalenumber10How strong the distortion is
value.xChannelSelectorstringRThe colour channel that moves pixels across: R, G, B or A
value.yChannelSelectorstringGThe colour channel that moves pixels up and down

tint ​

A flat colour wash over the blueprint, from one entry: the alert tint. The colour's alpha sets how much of the blueprint shows through.

  • It covers the blueprint's whole area, background included, not only its lines.

Loading live preview…

yaml
filters:
  - mode: svg
    type: tint
    value:
      color: alpha(var(--lcars-alert-red), 0.35)
KeyTypeDefaultDescription
value.colorcolourblack at 50%The wash colour, with its alpha, such as alpha(var(--lcars-alert-red), 0.35)

Recipes ​

Filter lists to copy for the usual looks. Each is a base_svg.filters value; change the numbers to taste.

Dimmed ​

Lower opacity and brightness: a quieter blueprint that still shows its detail. A good default.

yaml
type: custom:lcards-msd-card
grid_options:
  columns: full
  rows: 4
msd:
  base_svg:
    source: builtin:ncc-1701-a-blue
    filters:
      - type: opacity
        value: 0.5
      - type: brightness
        value: 0.8
  view_box: [180, 270, 1600, 720]

Subtle ​

A light fade with a slight blur and a little less colour: the detail stays, the weight goes.

yaml
type: custom:lcards-msd-card
grid_options:
  columns: full
  rows: 4
msd:
  base_svg:
    source: builtin:ncc-1701-a-blue
    filters:
      - type: opacity
        value: 0.6
      - type: blur
        value: 1px
      - type: grayscale
        value: 0.2
  view_box: [180, 270, 1600, 720]

Backdrop ​

Strong dimming with a blur, for displays full of data where the overlays carry everything.

        value: 0.6

Less colour and contrast with a fade: a muted, minimal look.
