LCARdS running live: every view below is made of real LCARdS cards from this version, on sample entities, laid out the way a Home Assistant sections view lays them out. Open a topic in the menu and pick a view, try the controls (the alert buttons, sliders, taps on the cards), then open YAML of this view to copy it, or follow the Docs button on the view to read about the feature. Show at the top of the menu picks one release: the views of what is new in 2026.11.0, or of an earlier release.

The same views make up the demo dashboard the LCARdS developers check every release on.

# Bridge: the "display over controls" archetype from doc/getting-started/lcars-design.md, in
# the classic TNG look. A thick sweep across the top carries labelled segments and the title.
# The main display charts power and shields over 24 hours inside a thin nested sweep, beside a
# ship status table (every number a labelled live reading) and the warp factor. The display's
# sidebar sweeps into a closing bar, and the next bar sweeps down into the control deck: pill
# groups led by big live numbers (their pills set power, shields, level, temperature and
# humidity, or toggle lights, doors and the auxiliary helper), a power slider, a shield gauge,
# main lights, a mode selector and red alert.

In your own Home Assistant ​

Paste a view's YAML into a dashboard (Edit dashboard > Raw configuration editor) and add the helpers it uses. The views drive lcards_test_* helpers (sliders, toggles, a select), so they work unchanged once those helpers exist: add this to configuration.yaml (or a file in your packages/ folder) and restart Home Assistant. Afterwards you can delete the helpers again, or swap them for your own entities in the YAML.

input_boolean:
  lcards_test_doors:
    name: LCARdS Test Doors
  lcards_test_lights:
    name: LCARdS Test Lights
  lcards_test_toggle:
    name: LCARdS Test Toggle
  lcards_test_visible:
    name: LCARdS Test Visible
  lcards_test_warp:
    name: LCARdS Test Warp
  lcards_test_warp_travel:
    name: LCARdS Test Warp Travel
    initial: true
input_datetime:
  lcards_test_date:
    name: LCARdS Test Date
    has_date: true
    has_time: true
input_number:

    name: LCARdS Test Humidity
    min: 0
    max: 100
    step: 1

    unit_of_measurement: '%'

    name: LCARdS Test Power
    min: 0
    max: 100
    step: 1

    unit_of_measurement: '%'
