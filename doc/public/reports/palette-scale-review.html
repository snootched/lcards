LCARdS 11-Stop Palette Scale — Review

solid dark border = canon anchor (unchanged) dotted gray border = interpolated (new) dashed red border = shipped slot-95 value (neon/electric extrapolation) dashed gray border = fade-to-white alternative (not shipped, comparison only) solid blue border = ha-lcars's generic &base formula (reference only — see note below)

Var name shown is the --lcards-<family>-<suffix> suffix actually referenced by the theme YAML (e.g. -darkest for the canon anchors, -10/-50/-60/-95 for the new computed stops).

About the blue-bordered row: this is not vanilla Home Assistant and not any currently-running theme. It's ha-lcars's own generic fallback mechanism (the &base block in ha-lcars/src/preamble.yaml, shared by every non-LCARdS theme in that repo) — color-mix(in oklch, seed N%, black/white) at fixed percentages, seeded from our own family's -40/base canon color. It answers: "if we'd only defined the base color and let ha-lcars generate the rest automatically like every other theme does, what would we have gotten?" — useful as a neutral baseline to see how far our hand-picked canon anchors diverge from an automatic ramp.
